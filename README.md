# Gani Rahmon — personal website

A responsive, dependency-free site for https://ganirahmon.github.io/. Content is based on the supplied CV, with education and education-specific awards omitted. The original CV is deliberately not included or linked because it contains education details.

## Preview

Serve this directory using any static HTTP server, or open `index.html` in a browser.

## GitHub Pages

Upload `index.html`, `styles.css`, and `.nojekyll` to the root of the `GaniRahmon/ganirahmon.github.io` repository. In repository Settings → Pages, select “Deploy from a branch,” then the branch containing these files and `/ (root)`.

No build or package installation is required. The publication links and profile links are taken from the CV. The contact email follows its visible text.
